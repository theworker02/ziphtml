# ziphtml

Zip and reshape html text streams with deterministic transforms.

**Site:** https://theworker02.github.io/ziphtml/

## Install / run

```bash
git clone https://github.com/theworker02/ziphtml.git
cd ziphtml
node src/cli.js
node --test
```
